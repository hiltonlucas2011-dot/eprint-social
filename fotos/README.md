# Fotos escolhidas pelo Hilton

Coloque aqui fotos de produtos para o agente usar nos posts.

## Como enviar pelo computador
1. Abra https://github.com/hiltonlucas2011-dot/eprint-social/tree/main/fotos (logado na conta `hiltonlucas2011-dot`).
2. Clique em **Add file → Upload files**, no canto superior direito da lista de arquivos.
3. **Arraste as fotos** para a página ou clique em *choose your files*.
4. Desça até o fim e clique em **Commit changes**. Pronto: o agente já enxerga as fotos.

## Pelo celular
O botão de envio só aparece no modo **"Site para computador"** do navegador (Safari: "aA" na barra de endereço). O app do GitHub não envia arquivos. No celular é mais fácil usar a aba **Minhas fotos** da página de aprovação.

**Nome do arquivo = produto que aparece na foto**, com hífens e sem acentos. Exemplos:
- `smartframe-backlight-vitrine.jpg`
- `caixa-oval-box-colorida.jpg`
- `papel-de-parede-escritorio.jpg`

Dicas: JPG ou PNG, de preferência com 1000 px ou mais, e sem marca ou logotipo de cliente.
O agente anota em `fotos/usos.md` em qual post cada foto foi usada.
